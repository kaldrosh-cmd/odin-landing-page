# Landing Page

A landing page built as part of the Foundations course of [The Odin Project](https://www.theodinproject.com/).

**Live demo:** https://kaldrosh-cmd.github.io/odin-landing-page/

## About

A recreation of a provided design using only HTML and CSS. The main goal was to practice building a complete page layout with Flexbox.

## What I practiced

- Planning the HTML structure first, then styling the page section by section
- Flexbox layouts: navbar, hero section, a row of cards, centering
- Nested flex containers and grouping elements so they can be laid out together
- The box model: padding, margin, borders and `box-sizing: border-box`
- Full-width section backgrounds with centered, width-limited content (`max-width` + `margin: 0 auto`)
- Keeping the footer at the bottom of the page (`min-height: 100vh` + `margin-top: auto`)
- CSS selectors (descendant, grouping) and inheritance

## Built with

- HTML5
- CSS3 (Flexbox)
